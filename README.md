# ChatDock（試作版）

ChatGPT の左サイドバーに、ブラウザ内だけで管理する独自ピン留め一覧を追加する Chrome 拡張です。対象は `https://chatgpt.com/*` のみで、会話本文を保存・送信しません。

## 現在の機能

- 表示中の ChatGPT チャットをピン留め
- ピン留め済みチャットの一覧表示と移動
- ピン留め解除

一覧はChatGPTの公式「ピン留め」の直後、「最近」の前に表示されます。ChatGPTのUI構造が大きく変わり、適切な挿入先を見つけられない場合は表示しません。

## インストール（開発者モード）

1. Chrome で `chrome://extensions` を開く。
2. 右上の「デベロッパー モード」を有効にする。
3. 「パッケージ化されていない拡張機能を読み込む」を選ぶ。
4. このフォルダーを選ぶ。

## 保存する情報

Chrome のローカルストレージに、チャットID、サイドバーに表示されたタイトル、ピン留め日時だけを保存します。外部サーバー通信、分析・追跡、会話本文・入力内容・Cookie・認証情報の保存はありません。

## MVPに含まれない機能

色分け、並べ替え、固定順、フォルダ、検索、同期、外部サービス対応は含みません。

## 公開時の注意

Chrome Web Storeへ公開する場合は、ローカル保存のみであっても、保存するデータと外部送信しないことを明示した正確なプライバシーポリシーおよびストア掲載情報を用意してください。
