# ChatRivet

ChatGPT の左サイドバーに、ブラウザ内だけで管理する独自ピン留め一覧を追加する Chrome 拡張です。対象は `https://chatgpt.com/*` のみで、会話本文を保存・送信しません。

## 現在の機能

- 表示中の ChatGPT チャットをピン留め
- ピン留め済みチャットの一覧表示と移動
- ピン留め解除
- ピンごとの色分け（固定8色）
- 専用ドラッグハンドルによるピンの手動並べ替え
- ChatRivetに追加したチャットを公式「最近」一覧では非表示にし、解除後に再表示

一覧はChatGPTの公式「ピン留め」の直後、「最近」の前に表示されます。ChatGPTのUI構造が大きく変わり、適切な挿入先を見つけられない場合は表示しません。

## インストール（開発者モード）

1. Chrome で `chrome://extensions` を開く。
2. 右上の「デベロッパー モード」を有効にする。
3. 「パッケージ化されていない拡張機能を読み込む」を選ぶ。
4. このフォルダーを選ぶ。

## 保存する情報と権限

`storage` 権限を使用し、Chrome のローカルストレージにチャットID、サイドバーに表示されたタイトル、ピン留め日時、ユーザーが選択した色、ユーザーが設定したピンの表示順だけを保存します。外部サーバー通信、分析・追跡、会話本文・入力内容・Cookie・認証情報の取得または保存はありません。

保存単位はChatGPTアカウントではなくChromeプロファイルです。同じChromeプロファイル内で複数のChatGPTアカウントを切り替えると、ChatRivetのピン一覧は共有されます。アカウントごとに分けるには、Chromeプロファイルを分けてください。

詳しくは[プライバシーポリシー](PRIVACY.md)を参照してください。

## MVPに含まれない機能

固定順、フォルダ、検索、同期、外部サービス対応は含みません。
